# 三相逆变电压采样赛题标定流程

## 1. 标定目标与边界

本流程针对三相逆变器的三路线电压采样通道：

```text
VUV = U相 - V相
VVW = V相 - W相
VWU = W相 - U相
```

根据《A题_AC-AC变换电路》要求，三相输出线电压为：

```text
Uo = 32 V RMS ±0.1 V
fo = 60 Hz ±0.2 Hz
fo = 30 Hz ±0.2 Hz
```

三相输出线电流为2.0 A RMS。第7项虽然将单相输入电压Ui调整到31～41 V，但逆变输出线电压仍为32 V RMS。因此，VUV、VVW、VWU的主要标定对象始终是32 V RMS输出线电压，而不是单相输入电压Ui。

为了给闭环控制、温漂和仪表误差保留余量，建议电压采样链在32 V工作点的自身误差控制在约±0.05 V以内。

## 2. 当前软件能力和限制

当前工程已经支持：

- `INV_CAL_STEP_ZERO`：同时计算六路ADC零点。
- `INV_CAL_STEP_GAIN`：计算单个通道的比例和极性。
- ADC标定模式下无条件关闭HRTIM物理PWM输出。
- VUV、VVW、VWU分别对应标定通道3、4、5。

当前GAIN算法为：

```text
recommended_scale = 已知静态物理量 / (raw_average - offset)
```

因此，现有GAIN步骤只适用于稳定直流或准静态输入，不能把32 V RMS正弦直接填入`INV_USER_CALIBRATION_REFERENCE`。正弦信号的平均值接近零，无法用平均码直接计算交流比例。

完整的赛题标定应分为：

1. 使用现有ZERO步骤完成三路零点标定。
2. 如果采样前端支持直流，使用正负直流完成增益和极性标定。
3. 使用30 Hz和60 Hz交流信号完成赛题工况复核。
4. 若需要直接用交流计算比例，应在10 kHz采样路径内增加一秒RMS统计，不能用当前100 Hz VOFA遥测数据代替。

## 3. ADC与DMA映射

| 物理信号 | ADC/DMA位置 | 标定通道 |
| --- | --- | --- |
| VUV | `INV_Adc3Dma[1]` | `INV_CAL_CHANNEL_VUV` |
| VVW | `INV_Adc4Dma[1]` | `INV_CAL_CHANNEL_VVW` |
| VWU | `INV_Adc5Dma[1]` | `INV_CAL_CHANNEL_VWU` |

标定前分别改变一路输入，确认只有对应DMA下标明显变化，避免采样板排线或ADC Rank顺序错误。

## 4. 标定前准备

1. 断开功率母线。
2. 关闭MOSFET驱动板12 V供电。
3. 保持采样板、STM32系统板和调试串口正常供电。
4. 使用隔离且经过校准的电压源。
5. 使用真有效值万用表或功率分析仪测量采样板输入端实际电压。
6. 采样板预热2～5分钟后再开始记录数据。
7. 检查5 V、3.3 V和1.65 V参考电压是否稳定。
8. 禁止向仍连接运放输出的ADC引脚直接注入外部电压。

## 5. 三路零点标定

### 5.1 软件设置

在`inv_user_config.h`中设置：

```c
#define INV_USER_WORK_MODE          INV_MODE_ADC_CALIBRATION
#define INV_USER_ENABLE_PWM_OUTPUT  0U

#define INV_USER_CALIBRATION_STEP   INV_CAL_STEP_ZERO
```

### 5.2 物理条件

- U、V、W三个电压采样输入保持相同电位。
- VUV、VVW、VWU的真实线电压均为0 V。
- 功率桥不工作。
- 标定期间不移动排线和探头。

### 5.3 操作步骤

1. 重新编译并下载程序。
2. 复位STM32。
3. 等待`inv_calibration_result.complete`变为1。
4. 确认`inv_calibration_result.valid=1`。
5. 确认`fault_bits=0x000`。
6. 记录：

```text
offset[3] = VUV零点
offset[4] = VVW零点
offset[5] = VWU零点
```

7. 写回配置：

```c
#define INV_USER_VUV_OFFSET  实测offset[3]
#define INV_USER_VVW_OFFSET  实测offset[4]
#define INV_USER_VWU_OFFSET  实测offset[5]
```

零点理论上约为2048码，但三路必须分别测量，不能用同一个值代替。

零点异常时优先检查：

- 1.65 V参考是否稳定。
- 采样板SGND与系统板地是否连通。
- 运放输出是否贴近0 V或3.3 V。
- 排线是否错位或断线。
- 输入端是否真正为零线电压。

## 6. 直流增益与极性标定

本步骤的前提是电压采样前端能够传递直流。如果输入侧存在隔直电容或电压互感器，应跳过本步骤，改用交流RMS统计法。

### 6.1 VUV标定示例

```c
#define INV_USER_WORK_MODE              INV_MODE_ADC_CALIBRATION
#define INV_USER_CALIBRATION_STEP       INV_CAL_STEP_GAIN
#define INV_USER_CALIBRATION_CHANNEL    INV_CAL_CHANNEL_VUV
#define INV_USER_CALIBRATION_REFERENCE  (10.000f)
```

向VUV输入施加准确的`+10.000 V DC`，重新编译、下载并复位，记录：

```text
inv_calibration_result.raw_average
inv_calibration_result.recommended_scale
inv_calibration_result.complete
inv_calibration_result.valid
```

再施加`-10.000 V DC`：

```c
#define INV_USER_CALIBRATION_REFERENCE (-10.000f)
```

正负输入得到的`recommended_scale`应符号相同、绝对值接近。

### 6.2 推荐直流测试点

```text
-45、-30、-15、-5、0、+5、+15、+30、+45 V DC
```

32 V RMS正弦的峰值约为：

```text
32 × sqrt(2) ≈ 45.25 V
```

因此，±45 V可以覆盖赛题额定输出的瞬时峰值。高压测试点只用于短时间量程检查。

分别对VUV、VVW和VWU重复以上步骤。

## 7. 交流赛题量程标定

### 7.1 推荐测试点

```text
0、5、10、20、28、30、31、32、33、34、36、38 V RMS
```

| 测试点 | 作用 |
| ---: | --- |
| 5、10 V | 检查低压分辨率和噪声影响 |
| 20、28 V | 检查中量程线性 |
| 30～34 V | 重点覆盖32 V闭环工作区 |
| 32 V | 赛题额定输出线电压 |
| 36 V | 检查输出过冲余量 |
| 38 V | 检查最大量程和削顶，不作为主要拟合点 |

每个点先在60 Hz下标定，再至少在30 Hz下复核：

```text
20、28、32、36、38 V RMS
```

每个测试点稳定后至少记录3个一秒窗口，标准电压必须在采样板输入端测量。

## 8. 交流比例计算

### 8.1 推荐RMS算法

在10 kHz ADC采样路径内累计整整1秒：

```text
code_rms = sqrt(sum((raw[n] - offset)^2) / N)

K = 标准仪表读取的Vrms / code_rms
```

分别得到：

```text
K_VUV
K_VVW
K_VWU
```

RMS方法比单纯使用最大值和最小值更适合最终系统，因为PWM纹波、谐波和偶然尖峰不会被直接当成基波峰值。

当前VOFA每10 ms发送一次，即100 Hz，不能可靠重建60 Hz正弦并计算RMS。RMS累计必须在10 kHz采样路径内完成，VOFA只发送最终统计结果。

### 8.2 临时峰值法

若标定源为低失真正弦，并且暂时只能获得`raw_min/raw_max`，可以使用：

```text
Acode = (raw_max - raw_min) / 2

K = Vrms × sqrt(2) / Acode
```

峰值法不建议作为最终高精度闭环的唯一标定依据。

## 9. 最终比例选取

不要只使用32 V一个点。推荐对每个通道使用20～36 V的测量数据进行过原点最小二乘拟合：

```text
K = Σ(code_rms_i × Vrms_i) / Σ(code_rms_i²)
```

38 V点主要检查量程。如果高电压端已经出现削顶或明显非线性，应将其排除在拟合数据之外。

最终分别填写：

```c
#define INV_USER_VUV_SCALE_V_PER_COUNT  实测K_VUV
#define INV_USER_VVW_SCALE_V_PER_COUNT  实测K_VVW
#define INV_USER_VWU_SCALE_V_PER_COUNT  实测K_VWU
```

禁止只标定一路后将相同比例复制到另外两路。

## 10. ADC量程预期

假设38 V RMS对应ADC输入约0.2～3.1 V，32 V RMS时预计：

```text
ADC输入谷值 ≈ 0.429 V
ADC输入峰值 ≈ 2.871 V

12位ADC谷值码 ≈ 532
12位ADC峰值码 ≈ 3563
```

38 V量程验收建议：

```text
raw_min > 200～250
raw_max < 3840～3900
```

同时检查：

- 峰顶和谷底没有变平。
- 正负半周平滑且基本对称。
- 中心码接近该通道零点码。
- 1.65 V中心不会随输入幅值明显漂移。
- 运放输出没有振荡。
- 三个通道没有明显增益差异。

## 11. 30 Hz与60 Hz频率一致性

分别计算30 Hz和60 Hz下的比例：

```text
频率差 = |K30 - K60| / ((K30 + K60) / 2) × 100%
```

建议判据：

- 小于0.15%：可以使用同一比例。
- 0.15%～0.3%：复核仪表精度、采样窗口和模拟滤波器。
- 超过0.3%：模拟前端存在明显频率响应差异，应调整滤波器或增加频率补偿。

赛题的`±0.1 V / 32 V`约为±0.3125%，测量链的频率响应误差不能占满全部误差预算。

## 12. 极性与三相一致性

统一极性定义：

```text
VUV > 0：U端瞬时电压高于V端
VVW > 0：V端瞬时电压高于W端
VWU > 0：W端瞬时电压高于U端
```

`recommended_scale`允许为负数。负号代表模拟采样链反相，不应为了让比例为正而在控制算法其他位置再次隐藏反号。

最终三相运行时应满足：

```text
VUV + VVW + VWU ≈ 0
```

三路线电压有效值应满足：

```text
VUV_rms ≈ VVW_rms ≈ VWU_rms ≈ 32.00 V
```

30 Hz和60 Hz都必须复核。

## 13. 工程量复核模式

写入三路offset和scale后设置：

```c
#define INV_USER_WORK_MODE          INV_MODE_OPEN_LOOP
#define INV_USER_ENABLE_PWM_OUTPUT  0U
```

保持PWM物理输出关闭，只验证ADC工程量换算。

当前OPEN_LOOP模式启动时会自动进行256帧零点平均。因此复位时必须先保持三路线电压为0，等待零点完成后再施加交流标定信号。若复位时已经存在30 Hz或60 Hz交流，程序可能把部分交流波形错误计入零点，30 Hz下尤其明显。

## 14. 最终验收标准

- VUV、VVW、VWU三路DMA映射正确。
- 三路零点分别完成，没有贴轨或同步故障。
- 三路比例独立标定，并包含正确极性。
- 32 V RMS时单通道测量误差尽量不超过±0.05 V。
- 三相通道之间的RMS差值不超过0.05～0.1 V。
- 30 Hz和60 Hz下均能准确测量32 V RMS。
- `line_voltage_sum`围绕零波动。
- 36 V和38 V测试点没有削顶、饱和或明显中心漂移。
- 标定和工程量复核期间HRTIM物理PWM始终关闭。
- 完成以上验收后，才进入5 V限流开环功率测试。
