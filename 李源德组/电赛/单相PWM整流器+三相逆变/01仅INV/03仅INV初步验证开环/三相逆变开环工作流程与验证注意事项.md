# 三相逆变无采样板开环工作流程、验证方法与注意事项

## 1. 文档依据与当前测试边界

本文依据`03仅INV初步验证开环`工程当前的`main.c`、`inv_open_loop`、`CBSVPWM`、`inv_hrtim`和`inv_measure`编写，适用于暂不连接ADC采样板、先验证SVPWM和三相逆变功率板的阶段。

当前关键编译开关为：

```c
#define INV_ENABLE_PWM_OUTPUT          (1U)
#define INV_SVPWM_ONLY_NO_ADC_MODE     (1U)
```

| 项目 | 当前设置 |
| --- | --- |
| 直流母线 | 5 V限流输入 |
| 理论输出目标 | 2.5 V RMS三相线电压基波 |
| 输出频率 | 默认60 Hz，可由软件切换为30 Hz |
| PWM与控制频率 | 10 kHz |
| 功率桥臂 | HRTIM Timer C、D、E，对应U、V、W |
| 调制算法 | 三桥臂`CBSVPWM_Calc3Leg()` |
| 控制节拍 | ADC3双Rank DMA完整传输回调，约10 kHz |
| ADC采样值 | 不参与控制、零偏、同步或保护判断 |
| 默认关闭 | PFC、HRTIM F、N桥臂、COMP和三相四线算法 |

> **重要：**该模式不是“完全关闭ADC”。ADC3/4/5和DMA仍会初始化并启动，其中ADC3 DMA完整传输回调是10 kHz SVPWM控制入口。只是不读取浮空ADC值，也不要求连接采样板。

### 1.1 当前模式临时旁路的功能

- 跳过256帧ADC零点标定等待。
- 不要求测量快照的`offset_ready`和`valid`有效。
- 不执行ADC3/4/5拼帧和序列同步保护。
- 不执行ADC原始码连续贴轨保护。
- ADC错误回调和模拟看门狗回调暂时不关断PWM。
- ADC4、ADC5 DMA完成回调不进入快速控制。
- OLED和VOFA中的六路“已发布测量快照”不代表实际输入。

### 1.2 当前仍然有效的保护和监督

- PB10/HRTIM1_FLT3硬件关断。
- HRTIM Fault 3回调的软件故障锁存。
- 开环参数、CBSVPWM结果和占空比合法性检查。
- HRTIM比较值写入失败处理。
- 10 kHz控制心跳的100 ms监督。
- CSS时钟故障、HardFault和不可恢复HAL错误关断。
- 故障后停止刷新IWDG并禁止自动重新开放PWM。

PB10必须保持确定的高电平。如果PB10为低或悬空，HRTIM Fault 3会直接强制C/D/E输出为Inactive，注释软件判断也无法恢复PWM。不得为了带功率测试而关闭FLT3。

## 2. PWM、驱动板和功率桥臂路径

```text
STM32G474
  HRTIM Master提供统一时基
        |
        +-> Timer C/D/E产生六路10 kHz互补PWM
        |
        +-> Master CMP2产生ADC Trigger 2
                         |
                         v
                  ADC3 DMA完整回调
                         |
                         v
              DDS -> CBSVPWM -> CMP1更新

TC1/TC2、TD1/TD2、TE1/TE2
        |
        v
三块UCC21520驱动板
        |
        v
三相功率板U/V/W三个半桥
        |
        v
三相对称负载
```

### 2.1 PWM引脚映射

| 固件相别 | MCU引脚 | HRTIM输出 | 功率桥臂 |
| --- | --- | --- | --- |
| U相上/下管 | PB12/PB13 | TC1/TC2 | U相半桥 |
| V相上/下管 | PB14/PB15 | TD1/TD2 | V相半桥 |
| W相上/下管 | PC8/PC9 | TE1/TE2 | W相半桥 |

第4桥臂保持断开；HRTIM F、PC6和PC7不得启动。负载按三相三线连接，不把负载中性点接到第4桥臂。

### 2.2 无采样板模式下ADC的真实作用

| ADC | 当前DMA长度 | 当前作用 |
| --- | ---: | --- |
| ADC3 | 2个Rank | DMA完整传输回调作为唯一10 kHz控制节拍 |
| ADC4 | 2个Rank | 仍启动以保持IOC结构，但回调不参与控制和保护 |
| ADC5 | 2个Rank | 仍启动以保持IOC结构，但回调不参与控制和保护 |

三个ADC输入可以暂时不接采样板，但不得外接超过0～3.3 V的信号。浮空输入可能产生随机ADC码，这是模拟输入的正常现象，不代表SVPWM算法异常。

## 3. 当前固件启动流程

```text
HAL初始化和170 MHz系统时钟
-> GPIO、DMA、HRTIM、ADC3/4/5、USART2初始化
-> 关闭HRTIM C/D/E六路物理输出
-> HAL_Delay(100)并初始化OLED
-> 初始化inv_measure、DDS开环参考和CBSVPWM
-> 校准ADC5、ADC4、ADC3
-> 按ADC5、ADC4、ADC3顺序启动循环DMA
-> 关闭三路DMA Half Transfer中断
-> 启动HRTIM Master和Timer C/D/E计数器
-> 跳过256帧ADC零偏和同步快照等待
-> 检查PB10为高且FLT3未置位
-> 初始化IWDG
-> 三相比较值设置为50%
-> 开放C/D/E六路PWM引脚
-> ADC3 DMA以10 kHz推进DDS和SVPWM
-> 1 s软启动到目标调制度
-> 进入60 Hz稳定开环运行
```

### 3.1 状态机表现

| `inv_state` | 状态 | 当前模式下的含义 |
| ---: | --- | --- |
| 0 | `INV_STATE_SAFE` | 初始化开始，PWM关闭 |
| 1 | `INV_STATE_ADC_CALIBRATION` | 执行ADC5/4/3内部校准 |
| 2 | `INV_STATE_ADC_OFFSET` | 启动HRTIM时基；当前模式立即跳过零偏等待 |
| 3 | `INV_STATE_READY` | 检查PB10/FLT3，PWM仍关闭 |
| 4 | `INV_STATE_SOFT_START` | 约1 s内调制度由0增加至目标值 |
| 5 | `INV_STATE_RUNNING` | 60 Hz稳定开环运行 |
| 6 | `INV_STATE_FAULT_LATCH` | 故障锁存，六路PWM关闭 |

正常情况下状态2停留时间很短，在Keil Watch中可能难以观察到。最终应稳定在状态5；若反复回到0或进入6，应先检查PB10、FLT3、控制心跳和电源复位。

## 4. 10 kHz SVPWM快速控制流程

当前无采样板模式的数据流是：

```text
HRTIM Master CMP2
-> ADC Trigger 2
-> ADC3完成两个Rank转换
-> ADC3 DMA Transfer Complete中断
-> HAL_ADC_ConvCpltCallback(ADC3)
-> INV_AppRunFastControl(NULL)
-> INV_OpenLoop_Step()推进32位DDS和软启动
-> 生成U/V/W三相正弦电压指令
-> CBSVPWM_Calc3Leg()执行零序注入
-> 检查valid、limited和占空比范围
-> INV_HRTIM_SetDuty()
-> CMP1预装载在HRTIM更新边界同步生效
-> inv_control_heartbeat增加1
```

ADC4和ADC5也会产生DMA完整回调，但当前条件编译分支直接忽略它们，因此每个10 kHz周期只运行一次控制算法。

快速回调中禁止调用`HAL_Delay()`、阻塞式USART、OLED刷新或动态内存。VOFA和OLED只能在主循环低速运行。

## 5. 调制比、占空比与HRTIM比较值

### 5.1 当前目标调制比

三相三线对称输出满足：

```text
Vphase_peak = Vline_rms * sqrt(2/3)
M = 2 * Vphase_peak / Vdc
  = 2 * Vline_rms * sqrt(2/3) / Vdc
```

当前参数为5 V母线、2.5 V RMS线电压，因此：

```text
M = 2 * 2.5 * sqrt(2/3) / 5
  ≈ 0.8165
```

`M=0.8165`表示三相正弦相电压指令的归一化峰值，不表示某一路PWM固定为81.65%占空比。

### 5.2 SVPWM零序注入后的占空比

`CBSVPWM_Calc3Leg()`先计算公共零序分量，再得到三个桥臂调制量：

```text
zero_sequence = -(maximum + minimum) / 2

modulation_u = normalized_u + zero_sequence
modulation_v = normalized_v + zero_sequence
modulation_w = normalized_w + zero_sequence
```

最终占空比为：

```text
duty_u = (1 + modulation_u) / 2
duty_v = (1 + modulation_v) / 2
duty_w = (1 + modulation_w) / 2
```

对平衡三相正弦，完整电周期内单桥臂理论占空比范围为：

```text
duty_min = 0.5 - sqrt(3) / 4 * M
duty_max = 0.5 + sqrt(3) / 4 * M
```

当前软启动过程对应：

| 软启动进度 | 有效调制比 | 理论占空比总范围 | CMP1大致范围 |
| ---: | ---: | ---: | ---: |
| 0% | 0 | 50.0% | 17000 |
| 25% | 0.2041 | 41.2%～58.8% | 20005～13995 |
| 50% | 0.4082 | 32.3%～67.7% | 23010～10990 |
| 75% | 0.6124 | 23.5%～76.5% | 26016～7984 |
| 100% | 0.8165 | 14.6%～85.4% | 29021～4979 |

HRTIM采用反向映射：

```text
CMP1 = 34000 * (1 - duty)
```

所以占空比增大时，CMP1反而减小。软件还限制占空比为5%～95%，对应CMP1约32300～1700；当前目标不会触及该限制。

`inv_svpwm.duty_u/v/w`包含公共零序分量，不是三个以50%为固定中心的纯正弦曲线。判断SVPWM正确性应看相间关系、线电压和60 Hz包络，不能只拿单相占空比与正弦公式直接比较。

## 6. 推荐分级验证流程

### 6.1 P0：只验证程序运行，不开放PWM引脚

1. 将`INV_ENABLE_PWM_OUTPUT`临时改为`0U`。
2. 只给系统板供电，不接驱动板PWM线，不上功率母线。
3. 编译并下载程序。
4. 在Keil Watch观察`inv_state`、`inv_control_heartbeat`、`inv_sine_u`和`inv_svpwm`。
5. `inv_state`应进入5，`inv_control_heartbeat`应持续增加。
6. `inv_sine_u`应为约-1～1的60 Hz单位正弦。
7. `duty_u/v/w`应按60 Hz变化，但MCU物理PWM引脚保持关闭。

### 6.2 P1：验证MCU六路HRTIM输出

1. 恢复`INV_ENABLE_PWM_OUTPUT = 1U`。
2. 保持驱动板PWM线断开、功率母线断电。
3. 确认PB10由可靠上拉保持高电平。
4. 测量PB12/PB13、PB14/PB15和PC8/PC9。
5. 每组应为10 kHz互补PWM，死区起点约500 ns。
6. 使用2～5 ms/div和持久显示观察60 Hz占空比包络。
7. 人工将PB10拉低，六路输出应由HRTIM硬件立即变为Inactive且不能自动恢复。

### 6.3 P2：驱动板无功率母线验证

1. 功率板5 V母线继续断开。
2. 给驱动逻辑侧和隔离驱动侧供电。
3. 每次只连接一组桥臂PWM，逐组核对U、V、W线序。
4. 使用差分或隔离方式测量每个MOSFET的Gate-Source。
5. 确认上下管对应、互补关系、实际死区和驱动幅值。
6. 三组全部通过后，再连接完整三相驱动。

高侧Gate必须相对Source测量，禁止把普通示波器地夹直接接到浮动开关节点。

### 6.4 P3：5 V限流带功率验证

1. 使用5 V可调限流直流电源，从较小电流限值开始。
2. 使用三相对称阻性负载，第4桥臂和中性点保持断开。
3. 先上控制和驱动辅助电源，确认PWM、死区和状态正常。
4. 最后接通5 V功率母线。
5. 先观察输入电流，再观察三个桥臂中点和滤波后线电压。
6. 正常后再缓慢提高电流限值，不直接提高母线电压。
7. 出现电流突升、桥臂发热、上下管重叠或异常振铃时立即断开母线。

当前没有ADC采样保护，也没有驱动器nFAULT/DESAT/OCP反馈，因此实验人员断电和限流电源是本阶段必要的外部保护条件。

## 7. Keil Watch验证

建议加入：

```c
inv_state
inv_control_heartbeat
inv_control_max_cycles
inv_output_frequency_hz
inv_sine_u
inv_svpwm.valid
inv_svpwm.limited
inv_svpwm.applied_scale
inv_svpwm.modulation_u
inv_svpwm.modulation_v
inv_svpwm.modulation_w
inv_svpwm.duty_u
inv_svpwm.duty_v
inv_svpwm.duty_w
```

正常表现：

| 变量 | 正常预期 |
| --- | --- |
| `inv_state` | 软启动后稳定为5 |
| `inv_control_heartbeat` | 约以10 kHz持续增加并自然溢出 |
| `inv_output_frequency_hz` | 默认60 |
| `inv_sine_u` | -1～1的60 Hz单位正弦 |
| `inv_svpwm.valid` | 1 |
| `inv_svpwm.limited` | 稳态不应持续为1 |
| `inv_svpwm.applied_scale` | 正常为1.0 |
| `duty_u/v/w` | 软启动后约在14.6%～85.4%内周期变化 |

Keil Watch的刷新速度远低于10 kHz，直接观察时可能只看到跳动的离散值。暂停CPU会同时停止PWM控制和IWDG刷新，只允许在功率母线断开时使用断点、单步或长时间暂停。

## 8. OLED与VOFA在当前模式下的反应

### 8.1 OLED显示

当前布局仍为：

```text
IU:xxxx UV:xxxx
IV:xxxx VW:xxxx
IW:xxxx WU:xxxx
F:60Hz  E:xxx
```

在无采样板模式下，`inv_measure`没有通过ADC拼帧发布六路新快照，因此OLED的六路ADC数字通常保持初始化值0。即使直接查看DMA数组得到浮空噪声，OLED也不会把它当作有效测量发布。

有效显示项是：

- `F`：正常应显示60 Hz。
- `E`：正常为`000`；发生FLT3、控制超时或算法错误后显示锁存故障码。

OLED每100 ms刷新一次。刷新较慢属于正常现象；整屏反复重启通常表示IWDG复位、系统供电跌落或程序进入不可恢复错误。

### 8.2 VOFA通道

USART2保持460800 baud、8N1、JustFloat，每10 ms发送一次：

| 通道 | 当前数据 | 无采样板模式下的预期 |
| ---: | --- | --- |
| CH0 | U相DDS单位正弦 | 有效，应为-1～1、60 Hz |
| CH1 | IU已发布快照 | 通常为0，无测量意义 |
| CH2 | IV已发布快照 | 通常为0，无测量意义 |
| CH3 | IW已发布快照 | 通常为0，无测量意义 |
| CH4 | VUV已发布快照 | 通常为0，无测量意义 |
| CH5 | VVW已发布快照 | 通常为0，无测量意义 |
| CH6 | VWU已发布快照 | 通常为0，无测量意义 |
| CH7 | 锁存故障位 | 正常为0 |

CH0只能验证DDS频率、相位推进和USART链路，不包含软启动调制度。软启动应观察`reference.ramp`、`inv_svpwm.duty_*`或示波器上的占空比包络。

如果CH0停止变化，同时`inv_control_heartbeat`不再增加，优先检查ADC3 DMA完整中断、HRTIM Trigger 2和控制超时故障，而不是先排查ADC输入电压。

## 9. 当前模式故障码

| OLED代码 | 当前是否主动使用 | 含义或说明 |
| ---: | --- | --- |
| `001` | 临时旁路 | ADC同步失步；当前模式不拼接三ADC快照 |
| `002` | 启动阶段可能出现 | ADC校准或DMA启动失败；运行期ADC错误回调被临时忽略 |
| `004` | 临时旁路 | ADC持续贴轨；当前模式不检查浮空采样值 |
| `008` | 保留 | HRTIM启动、更新失败或FLT3有效 |
| `010` | 临时旁路 | ADC模拟看门狗越界 |
| `020` | 保留 | 占空比或HRTIM比较值非法 |
| `040` | 保留 | CBSVPWM计算失败或持续限幅 |
| `080` | 保留 | 开环母线、输出电压、频率或软启动参数非法 |
| `100` | 保留 | CSS检测到HSE时钟故障 |
| `200` | 保留 | ADC3 DMA驱动的控制心跳停止 |
| `400` | 保留 | IWDG刷新失败或其他不可恢复系统错误 |

多个故障位会按位或。例如`208`表示`200 + 008`。故障锁存后，程序关闭六路PWM、复位DDS/CBSVPWM状态、不自动恢复并停止正常喂狗。

### 9.1 常见异常

| 现象 | 优先原因 | 处理方法 |
| --- | --- | --- |
| 没有任何PWM | PB10为低、FLT3已置位、`INV_ENABLE_PWM_OUTPUT=0` | 测PB10、复位清除Fault、核对编译开关 |
| 状态进入6且`E:008` | FLT3有效或HRTIM启动/更新失败 | 确保PB10可靠为高，核对HRTIM C/D/E计数器和输出状态 |
| `E:200` | ADC3 DMA完整回调停止，控制心跳超时 | 检查Trigger 2、ADC3 DMA IRQ、DMA TC中断和HRTIM Master |
| OLED六路ADC全为0 | 当前不发布ADC快照 | 无采样板模式下属于预期，不代表DMA停止 |
| DMA原始数组随机跳动 | ADC输入悬空 | 属于预期；当前模式不读取这些值 |
| CH0正常但CH1～CH6为0 | DDS/USART正常，采样发布被旁路 | 当前模式正常表现 |
| `duty_u/v/w`始终约0.5 | 仍在软启动起点、状态未进入4/5或控制未推进 | 看`inv_state`、心跳、`reference.ramp`及故障位 |
| MCU脚10 kHz稳定但桥臂节点频率不定 | SVPWM脉宽不断变化，示波器自动频率误判 | 以MCU单路PWM判断载波，用慢时基/FFT判断60 Hz |
| 输入电流突升或MOSFET发热 | 上下管映射错误、死区不足、接线或功率桥故障 | 立即断开5 V母线，重新从P1/P2逐桥臂验证 |
| 输出低于2.5 V RMS | 母线压降、MOSFET/死区压降、滤波和负载影响 | 当前为理论开环目标，不承诺精密稳压 |

## 10. 当前保护能力和禁止事项

### 10.1 当前仍可依赖的软件/外设措施

- HRTIM Output Stop关闭C/D/E六路输出。
- PB10真实拉低时，FLT3可在不依赖CPU的情况下强制输出Inactive。
- 控制心跳停止可在100 ms监督周期内锁存故障。
- CBSVPWM、占空比、参数、CSS和CPU异常能够触发安全关断。

### 10.2 当前不能依赖的保护

- ADC过流、过压、欠压和采样贴轨保护。
- ADC3/4/5同步失步检测。
- ADC模拟看门狗保护。
- 三相电流或线电压物理量阈值。
- 驱动器nFAULT、DESAT或OCP反馈。
- 自动预充、自动放电和独立Gate Enable。

因此本模式禁止：

- 提高直流母线电压。
- 使用大电流或不明确的负载。
- 无人监护运行。
- 将保险丝视为MOSFET微秒级短路保护。
- 在ADC保护未恢复时开展赛题额定电压或闭环测试。

## 12. 恢复ADC采样板后的操作

接回采样板并准备恢复采样保护时，必须先断开功率母线，将：

```c
#define INV_SVPWM_ONLY_NO_ADC_MODE (0U)
```

然后重新编译下载，并依次验证：

1. 采样板5 V、3.3 V和1.65 V中点参考正常。
2. 六路ADC零输入码接近各自中点且远离0/4095。
3. ADC3/4/5序列同步推进。
4. 约25.6 ms后`offset_ready=1`，随后`valid=1`。
5. OLED和VOFA六路数据开始反映已发布测量快照。
6. 停止任一路DMA能够锁存同步故障并关闭PWM。
7. ADC错误、贴轨和AWD保护经过低压故障注入验证。

不能只连接采样板而忘记把编译开关改回`0U`，否则ADC值虽然存在，保护代码仍然不会执行。

## 13. 后续修改输入、输出电压和频率

当前参数集中在`main.c`：

```c
#define INV_OPEN_LOOP_DC_BUS_V           (5.0f)
#define INV_OPEN_LOOP_LINE_RMS_V         (2.5f)
#define INV_OPEN_LOOP_DEFAULT_FREQUENCY  (INV_FREQ_60HZ)
#define INV_OPEN_LOOP_CONTROL_HZ         (10000U)
#define INV_OPEN_LOOP_SOFT_START_MS      (1000U)
#define INV_OPEN_LOOP_MODULATION_LIMIT   (0.90f)
```

修改母线或目标线电压前必须校核：

```text
M = 2 * Vline_rms * sqrt(2/3) / Vdc
M <= modulation_limit
```

30/60 Hz切换只改变DDS相位步进，不改变调制比和占空比幅值，并保持切换瞬间相位连续。

本工程的2.5 V RMS只是5 V母线下的理论开环目标。实际输出受母线压降、驱动压降、MOSFET导通压降、死区、滤波器和负载影响。赛题要求的额定电压和稳压精度必须增加实测母线、ADC比例标定、线电压RMS计算、电压闭环及有效硬件保护，不能只修改这两个电压宏。
