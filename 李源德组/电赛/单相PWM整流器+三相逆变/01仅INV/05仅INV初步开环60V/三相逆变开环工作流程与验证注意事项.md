# 60 V三相逆变开环工作流程、上板验证与异常处理

## 1. 文档依据与当前边界

本文依据以下实际文件重新核对：

- `02OpenLoop`工程当前的`main.c`、`inv_measure`、`inv_open_loop`、`CBSVPWM`和`inv_hrtim`。
- 系统板扩展板原理图。
- UCC21520 MOSFET驱动板原理图。
- 三相四线功率板原理图。
- 三相交流采样板原理图。

当前固件只运行三相三线逆变：

| 项目 | 当前设置 |
| --- | --- |
| 直流母线 | 60 V限流输入，电源限流上限3 A |
| 目标输出 | 32 V RMS三相线电压基波，理论开环值 |
| 输出频率 | 默认60 Hz，可通过软件切换30 Hz |
| PWM/控制频率 | 10 kHz |
| PWM桥臂 | HRTIM Timer C、D、E，对应U、V、W |
| ADC | ADC3、ADC4、ADC5，双Rank规则组循环DMA |
| 调制 | 三桥臂`CBSVPWM_Calc3Leg()` |
| 默认工作模式 | `INV_MODE_PWM_WAVEFORM`，开环PWM；ADC仅观测线电压 |
| 唯一用户配置入口 | `Core/Inc/inv_user_config.h` |
| 未启用资源 | PFC、HRTIM F、N桥臂、COMP和三相四线算法 |

功率板虽然做有四个桥臂，但当前只使用其中三个。第4桥臂不得接入控制输出，也不得把负载中性点接到该桥臂。

### 1.1 根据原理图得到的关键结论

1. 三相采样板使用3.3 V模拟电源和`1V65REF`中点偏置。正常供电且零电流、零交流电压时，六路ADC输出应接近1.65 V，即12位ADC中点码约2048，而不是0。
2. UCC21520驱动板的`DISABLE`固定在低电平有效状态。当前硬件没有由MCU控制的Gate Enable，所以软件开放HRTIM输出后，驱动器会立即响应PWM。
3. 驱动板没有向MCU返回nFAULT、DESAT或OCP信号。PB10/HRTIM1_FLT3没有接到这些保护信号时，只能用于人工拉低测试或未来扩展。
4. 功率板直流输入有T5A保险丝，但保险丝不能在MOSFET直通或短路的微秒级时间内完成保护，不能替代独立硬件过流保护。
5. 三相电压采样板按约29/36 V RMS量程设计。当前32 V RMS目标已接近其设计量程，接通母线前必须确认三路线电压采样在完整电周期内均远离0和4095，并通过实测标定确认量程余量。

本版本不使用电流采样，也不增加按安培值执行的过流关断。由于IOC的ADC Rank未改动，电流Rank仍会被ADC转换，但软件忽略其贴轨和物理量结果；三路线电压只用于OLED/VOFA观测，不参与开环调制。PWM不会因ADC数值贴轨而停波，但ADC3 DMA完全停止仍会因10 kHz控制心跳超时而停波。

### 1.2 集中配置改造

日常使用不再需要进入`main.c`、`inv_measure.c`或算法模块查找参数。只修改：

```text
Core/Inc/inv_user_config.h
```

三个模式为：

| 模式 | 用途 | PWM | ADC行为 |
| --- | --- | --- | --- |
| `INV_MODE_ADC_CALIBRATION` | 六路零点和单通道增益/极性标定 | 强制关闭 | 三ADC同步采样，输出标定结果 |
| `INV_MODE_PWM_WAVEFORM` | 60 V限流、32 V RMS目标开环PWM | 由用户开关决定 | 线电压仅观测；ADC数值不关闭PWM，ADC3 DMA仍提供10 kHz节拍 |
| `INV_MODE_OPEN_LOOP` | 完整ADC保护开环 | 由用户开关决定 | ADC有效性会影响PWM，不适合当前需求 |

标定模式在代码路径上不调用`INV_HRTIM_EnableOutputs()`；即使误把`INV_USER_ENABLE_PWM_OUTPUT`设为1，六路PWM也不会开放。

### 1.3 使用说明：以后只改一个文件

#### 1.3.1 每次修改的固定操作

1. 断开功率母线。涉及模式切换、ADC标定或PWM开放状态变化时，必须先断电再修改。
2. 用Keil打开`MDK-ARM/02OpenLoop.uvprojx`。
3. 在工程树中打开`Core/Inc/inv_user_config.h`。
4. 只修改“用户常用配置区”，不要修改上方模式/通道常量，也不要进入`main.c`或算法模块重复改参数。
5. 保存后执行`Build Target`；配置头文件发生变化时必须重新编译，不能只复位MCU。
6. 确认构建结果为`0 Error(s), 0 Warning(s)`，再下载程序并复位运行。
7. 先观察OLED、VOFA或Keil Watch确认模式和故障状态，再决定是否连接驱动板或功率母线。

Keil Watch可长期保留以下公共量：

```c
inv_work_mode                  // 0=ADC标定，1=MCU波形，2=完整开环
inv_state                      // 正常开环最终为5，标定完成停在3
inv_control_heartbeat          // 波形/开环模式约以10 kHz增加
inv_svpwm.valid
inv_svpwm.limited
inv_svpwm.duty_u
inv_svpwm.duty_v
inv_svpwm.duty_w
inv_calibration_result
```

调试器暂停CPU会同时暂停10 kHz控制和IWDG刷新。连接功率母线时禁止使用断点、单步或长时间暂停。

#### 1.3.2 四种常见任务怎么选

| 想做的事 | `INV_USER_WORK_MODE` | `INV_USER_ENABLE_PWM_OUTPUT` | 必要条件 |
| --- | --- | ---: | --- |
| ADC零点/增益标定 | `INV_MODE_ADC_CALIBRATION` | 任意，代码强制关闭 | 采样板供电，功率母线断开 |
| 只运行算法、不输出物理PWM | `INV_MODE_PWM_WAVEFORM` | `0U` | 可通过Watch观察占空比和CMP更新 |
| 示波器测MCU六路PWM | `INV_MODE_PWM_WAVEFORM` | `1U` | 驱动板和功率母线断开，PB10为高 |
| 60 V限流开环PWM | `INV_MODE_PWM_WAVEFORM` | `1U` | 采样板接好用于线电压观测，先完成低压分级验证 |

模式切换是编译期选择，不支持程序运行中切换。每次更改`INV_USER_WORK_MODE`后都必须重新编译和下载。

#### 1.3.3 推荐完整使用顺序

```text
ADC ZERO求六路offset
-> 把offset写回inv_user_config.h
-> ADC GAIN逐通道求scale和极性
-> 把六路scale写回inv_user_config.h
-> PWM_WAVEFORM且输出关闭，检查算法变量
 -> PWM_WAVEFORM且输出开放，示波器检查六路MCU PWM
 -> 线电压ADC只做OLED/VOFA观测，不参与开环调制
-> 驱动板无母线检查Gate-Source和实际死区
-> OPEN_LOOP，先低压限流确认，再逐级升到60 V
```

任何一步失败都停留在当前阶段，不跨级接通功率母线。

## 2. 四块板之间的数据与能量路径

```text
STM32G474系统板
  HRTIM C/D/E六路PWM
        |
        v
三块UCC21520驱动板
  5 V逻辑电源 + 12 V隔离电源
        |
        v
三相功率板的U/V/W三个半桥
  60 V直流母线 -> MOSFET桥 -> 470 uH输出电感 -> 三相负载
        |
        v
三相交流采样板
  三相电流 + U-V/V-W/W-U线电压 -> 1.65 V偏置ADC信号
        |
        v
ADC3/4/5 + DMA -> 同步快照 -> OLED/VOFA/开环控制
```

### 2.1 PWM与桥臂映射

| 固件相别 | MCU引脚 | HRTIM输出 | 驱动输入 | 功率桥臂 |
| --- | --- | --- | --- | --- |
| U上/下管 | PB12/PB13 | TC1/TC2 | PWMA/PWMB | U相半桥 |
| V上/下管 | PB14/PB15 | TD1/TD2 | PWMA/PWMB | V相半桥 |
| W上/下管 | PC8/PC9 | TE1/TE2 | PWMA/PWMB | W相半桥 |

每块驱动板上，PWMA对应UCC21520 A通道，PWMB对应B通道。接线后必须逐桥臂核对“A通道是否实际接上管、B通道是否实际接下管”，不能只按线色判断。

功率板的第4桥臂及其驱动接口保持断开。HRTIM F、PC6和PC7不得启动。

### 2.2 ADC映射

| 相别 | 采样板输出 | MCU引脚 | ADC与Rank | DMA位置 |
| --- | --- | --- | --- | --- |
| U相电流 | CURROUT1 | PB0 | ADC3 Rank 1 | `INV_Adc3Dma[0]` |
| U-V线电压 | VOLOUT1 | PD10 | ADC3 Rank 2 | `INV_Adc3Dma[1]` |
| V相电流 | CURROUT2 | PD8 | ADC4 Rank 1 | `INV_Adc4Dma[0]` |
| V-W线电压 | VOLOUT2 | PE14 | ADC4 Rank 2 | `INV_Adc4Dma[1]` |
| W相电流 | CURROUT3 | PD9 | ADC5 Rank 1 | `INV_Adc5Dma[0]` |
| W-U线电压 | VOLOUT3 | PD14 | ADC5 Rank 2 | `INV_Adc5Dma[1]` |

电压采样输入应分别跨接U-V、V-W和W-U，三路极性必须一致。若任意一路正负端接反，`VUV + VVW + VWU`将明显偏离0，且相位判断会错误。

### 2.3 供电与地

| 电路 | 必需供电/参考 | 检查重点 |
| --- | --- | --- |
| 系统板 | 5 V、3.3 V、MCU GND | VDDA/VREF正常，MCU稳定运行 |
| 采样板 | 5 V输入，板上AMS1117产生3.3 V | `1V65REF`约1.65 V，SGND与MCU模拟地可靠连接 |
| 驱动逻辑侧 | +5 V、DGND | UCC21520 VCCI正常，PWMA/PWMB参考DGND |
| 驱动隔离侧 | +12 V输入 | 两路隔离电源输出分别参考对应的VSSA/VSSB或SW节点 |
| 功率板 | 60 V直流母线、PGND | 必须限流，极性正确，先从低电压和低限流值分级验证 |

采样板的`1V65REF`是模拟信号偏置，不是MCU的VREF+供电。不得把它误接到系统板VREF引脚。

高侧驱动输出参考开关节点，不参考DGND或PGND。禁止用普通接地示波器探头把高侧Gate直接对PGND测量；应测Gate-Source并使用差分探头或隔离探头。

## 3. 推荐的分级上电流程

当前驱动板没有硬件Gate Enable，因此不能把所有板一次连接后直接上60 V母线。必须按以下阶段逐项通过。

### 3.1 P0：系统板和采样板验证，禁止功率输出

1. 设置`INV_USER_WORK_MODE = INV_MODE_ADC_CALIBRATION`及`INV_USER_CALIBRATION_STEP = INV_CAL_STEP_ZERO`并重新编译。
2. 只给系统板和采样板供电，不接驱动板PWM，不给功率板母线上电。
3. 用万用表测采样板3.3 V和`1V65REF`，后者应约为1.65 V。
4. 测六个CURROUT/VOLOUT输出。零输入时都应接近1.65 V，且不得高于MCU VDDA。
5. 观察OLED或VOFA，六路ADC应在各自中点附近稳定，不应出现`004`。
6. 确认三个ADC序列及`fast_heartbeat`约以10 kHz推进，`inv_state`最终进入5。

若P0失败，不得连接驱动板或功率母线。

### 3.2 P1：只验证MCU PWM引脚

1. 保持功率板母线断电，驱动板PWM线仍断开。
2. 设置`INV_USER_WORK_MODE = INV_MODE_PWM_WAVEFORM`及`INV_USER_ENABLE_PWM_OUTPUT = 1U`并重新编译。
3. 在PB12/PB13、PB14/PB15、PC8/PC9对MCU GND测量。
4. 六路应为固定10 kHz载波；每组上下管互补，死区起点约500 ns。
5. 使用较慢时基或示波器持久显示观察60 Hz占空比包络，而不是依赖自动频率测量桥臂节点。

### 3.3 P2：驱动板无母线验证

1. 先给驱动板+5 V逻辑电源和+12 V隔离电源供电，功率板60 V母线继续断开。
2. 逐块连接一组PWMA/PWMB，确认输入端仍是稳定10 kHz。
3. 用差分/隔离方式逐桥臂测Gate-Source，确认幅值、互补关系、死区和上/下管对应关系。
4. 核对UCC21520板上DT网络与HRTIM 500 ns死区叠加后的实际死区。最终值以Gate-Source实测为准。
5. 三块驱动板全部通过后，再连接到三个功率桥臂。

### 3.4 P3：60 V限流开环带功率验证

1. 使用可调限流电源，先把输出调到0 V并设置较小限流值；接线确认后从5 V、12 V、24 V等低压档逐级验证，最后才升到60 V。
2. 使用三相对称阻性负载；确认第4桥臂和中性点未参与。
3. 先上系统/采样/驱动辅助电源，确认`E:000`、ADC中点正常和PWM稳定。
4. 最后接通功率板母线，先在低电压档确认波形和输入电流正常，再逐级升压。
5. 到60 V之前先观察电源输入电流、三个桥臂中点和滤波后线电压；3 A只作为电源限流上限，不要求首次测试直接调到3 A。
6. 任一桥臂异常发热、输入电流突升、波形重叠或采样贴轨时立即断开母线，不等待软件或保险丝动作。

## 4. 固件启动状态与正常流程

```text
HAL、170 MHz时钟及CubeMX外设初始化
-> 关闭HRTIM C/D/E六路输出
-> OLED等待100 ms并初始化
-> 初始化测量、DDS和CBSVPWM
-> 校准ADC5、ADC4、ADC3
-> 启动ADC5、ADC4、ADC3循环DMA
-> 关闭三路DMA Half Transfer中断
-> 启动HRTIM Master和Timer C/D/E计数器
-> HRTIM Trigger 2以10 kHz触发ADC3/4/5
-> 收集256个六通道同步帧计算零点
-> 检查PB10/FLT3及ADC状态
-> 启动IWDG
-> 三相比较值先置50%
-> 开放C/D/E六路PWM
-> 1 s软启动到目标调制度
-> 60 Hz稳定开环运行
```

| `inv_state` | 状态 | 正常持续时间/含义 |
| ---: | --- | --- |
| 0 | `INV_STATE_SAFE` | 复位后短暂停留，PWM关闭 |
| 1 | `INV_STATE_ADC_CALIBRATION` | ADC5/4/3校准 |
| 2 | `INV_STATE_ADC_OFFSET` | 约25.6 ms完成256帧零点平均 |
| 3 | `INV_STATE_READY` | 启动条件检查，PWM仍关闭 |
| 4 | `INV_STATE_SOFT_START` | 约1 s，占空比包络逐渐展开 |
| 5 | `INV_STATE_RUNNING` | 正常稳定运行 |
| 6 | `INV_STATE_FAULT_LATCH` | 故障锁存，六路PWM关闭 |

程序在故障后停止刷新IWDG，约500 ms后可能复位。因此反复看到`0`、OLED重启或短暂PWM，不表示程序正在正常软启动。

## 5. 10 kHz快速控制数据流

```text
HRTIM Master CMP2
-> ADC Trigger 2
-> ADC3/4/5各完成两个Rank
-> 三路DMA完整传输回调
-> inv_measure发布一份六通道同步快照
-> 只执行一次INV_OpenLoop_Step()
-> 32位DDS生成U/V/W三相参考
-> CBSVPWM_Calc3Leg()计算三桥臂占空比
-> INV_HRTIM_SetDuty()写C/D/E CMP1预装载
-> HRTIM更新边界同步生效
```

三个DMA回调都会运行，但只有凑齐ADC3/4/5新序列的回调返回`true`，所以每个PWM周期只执行一次控制。OLED和VOFA不在该中断路径中运行。

60 V母线和32 V RMS目标对应的理论调制度约为0.871。软启动完成后，`inv_svpwm.duty_u/v/w`应明显围绕0.5周期变化；线电压ADC只用于观察，不参与调制度修正。

### 5.1 当前调制度与占空比的对应关系

当前程序首先计算相电压调制度：

```text
M = 2 * Vline_rms * sqrt(2/3) / Vdc
  = 2 * 32 * sqrt(2/3) / 60
  ≈ 0.8709
```

`M=0.8709`表示三相正弦相电压指令的归一化峰值，不表示某一路PWM固定为87.09%占空比。当前`CBSVPWM_Calc3Leg()`还会注入公共零序分量，最终使用：

```text
duty_u = (1 + modulation_u) / 2
duty_v = (1 + modulation_v) / 2
duty_w = (1 + modulation_w) / 2
```

对平衡三相正弦，经过当前最大/最小值零序注入后，任一桥臂在完整电周期内的理论占空比包络为：

```text
duty_min = 0.5 - sqrt(3) / 4 * M
duty_max = 0.5 + sqrt(3) / 4 * M
```

当前1 s线性软启动对应关系如下：

| 软启动进度`ramp` | 有效调制度`M*ramp` | 三路占空比完整周期理论范围 | CMP1大致范围，反向映射 |
| ---: | ---: | ---: | ---: |
| 0% | 0 | 50.0% | 17000 |
| 25% | 0.2177 | 40.6%～59.4% | 20206～13794 |
| 50% | 0.4355 | 31.1%～68.9% | 23411～10589 |
| 75% | 0.6532 | 21.7%～78.3% | 26617～7383 |
| 100% | 0.8709 | 12.3%～87.7% | 29822～4178 |

HRTIM层使用`CMP1 = 34000 * (1 - duty)`反向映射，因此占空比越大，CMP1越小。软件最终还把单桥臂占空比限制在5%～95%，对应CMP1约32300～1700；当前正常`M≈0.8709`不会触及该安全限幅，但距离0.90调制上限仅约0.029。

以U相电角度为例，当前相序定义为`U=sin(theta)`、`V=sin(theta-120°)`、`W=sin(theta+120°)`，软启动完成后的典型值为：

| U相角度 | `duty_u` | `duty_v` | `duty_w` | 说明 |
| ---: | ---: | ---: | ---: | --- |
| 0° | 50.0% | 12.3% | 87.7% | U相过中点，V/W相反向最大 |
| 30° | 82.7% | 17.3% | 82.7% | 零序注入使两路占空比相同 |
| 60° | 87.7% | 12.3% | 50.0% | U/V相差达到最大 |
| 90° | 82.7% | 17.3% | 17.3% | U相正峰值时占空比不是93.5% |

最后一行尤其容易误判：如果不考虑零序注入，可能按`0.5 + M/2`得到约93.5%；当前CBSVPWM加入公共零序后，U相在90°处约为82.7%，但线电压指令不变。示波器观察单桥臂时，应以本表和`inv_svpwm.duty_u/v/w`为准。

死区会缩短MOSFET实际导通时间，因此Gate或滤波后输出的有效占空时间会比软件命令略小；表中数值是写入HRTIM前的理论命令值。

## 6. ADC、零点与采样板验证

### 6.1 原始码的正确预期

采样板六路都使用`1V65REF`：

```text
零输入预期电压约1.65 V
12位ADC理论中点码 = 1.65 / 3.3 * 4095 ≈ 2048
```

实际每路会因运放、分压和ADC误差存在不同零点，所以程序用启动后的256帧平均值分别计算offset。正常范围不能简单限定为“必须等于2048”，但应明显远离0和4095，并且短时间内稳定。

当前软件规定任意通道连续8帧满足以下条件时锁存`004`：

```c
raw <= 16U || raw >= 4079U
```

10 kHz下8帧约0.8 ms。因此采样板未供电、SGND断开、输出线接错或ADC脚被短路时，会在完成256帧零点标定之前触发`004`。

### 6.2 上板测量顺序

1. 测采样板5 V输入。
2. 测AMS1117输出，应约3.3 V。
3. 测`1V65REF`，应约1.65 V。
4. 在采样板输出连接器处测六路，应接近1.65 V。
5. 在系统板ADC连接器处再次测六路，确认线缆没有断线或错位。
6. 在Keil Watch观察DMA原始数组，确认物理电压与ADC码对应。

不得在运放输出仍连接时用外部电源强行向ADC脚注入1.65 V，否则可能与采样板输出互相驱动。

### 6.3 运行观察量

```c
INV_Adc3Dma[0]
INV_Adc3Dma[1]
INV_Adc4Dma[0]
INV_Adc4Dma[1]
INV_Adc5Dma[0]
INV_Adc5Dma[1]
inv_control_heartbeat
inv_state
inv_svpwm.duty_u
inv_svpwm.duty_v
inv_svpwm.duty_w
```

结构体中的序列和状态通过`INV_Measure_GetSnapshot()`发布。Keil Watch通常在暂停CPU后刷新；暂停会停止实时控制，只能在功率母线断开时使用断点和单步。

### 6.4 三相三线一致性检查

完成比例和极性标定后，正常三相三线系统应满足：

```text
IU + IV + IW ≈ 0
VUV + VVW + VWU ≈ 0
```

当前代码只记录这两个和，不参与关断。未标定前只能用于观察趋势，不能设置严格阈值。

## 7. PWM、驱动与输出波形的正确观察方法

### 7.1 不同测点应该看到什么

| 测点 | 正常波形 | 频率判断方法 |
| --- | --- | --- |
| MCU TC1/TD1/TE1 | 10 kHz PWM，占空比带60 Hz包络 | 自动频率应接近10 kHz |
| MCU TC2/TD2/TE2 | 与同桥臂Output 1互补，含死区 | 同上 |
| UCC21520 PWMA/PWMB | 与MCU对应输出一致 | 对DGND测量 |
| MOSFET Gate-Source | 约驱动电源幅值的互补门极波形 | 必须差分/隔离测量 |
| 桥臂中点 | 0与5 V之间切换的SVPWM脉冲 | 自动频率可能跳动，不作为载波判据 |
| 滤波后线电压 | 60 Hz基波叠加开关纹波 | 用差分探头、FFT或RMS测量 |

测桥臂中点或U-V线电压时，SVPWM会产生宽度和间隔不断变化的脉冲，示波器自动频率显示不稳定是可能的。判断HRTIM载波是否稳定，必须回到单个MCU PWM引脚测量。

### 7.2 占空比变化不明显时

依次检查：

1. OLED故障码必须为`000`。
2. `inv_state`必须最终稳定为5，而不是在0/6间反复。
3. `inv_control_heartbeat`必须连续增加。
4. `inv_svpwm.valid`应为1，`limited`不应持续为1。
5. `duty_u/v/w`应随60 Hz相位变化，不应固定为0.5。
6. 示波器使用约2～5 ms/div和持久显示观察包络；仅看几个10 kHz周期时，占空比变化本来就不明显。

## 8. OLED与VOFA

### 8.1 OLED显示

```text
IU:xxxx UV:xxxx
IV:xxxx VW:xxxx
IW:xxxx WU:xxxx
F:60Hz  E:xxx
```

OLED每100 ms更新一次，即10 Hz。数字变化看起来有一定延迟是正常的，但整屏周期性熄灭、重新点亮或闪烁不是正常刷新，通常表示IWDG复位、5 V供电跌落或软件反复进入初始化。

ADC标定模式的第4行改为：

```text
C:x D:cv E:xxx
```

- `C`：当前标定通道编号，0～5依次为IU、IV、IW、VUV、VVW、VWU。
- `D`十位：`complete`，完成采集后为1。
- `D`个位：`valid`，结果有效时为1；`10`表示完成但码差不足。
- `E`：锁存故障位。

### 8.2 VOFA通道

USART2为460800 baud、8N1，JustFloat，每10 ms发送一次：

| 通道 | 数据 | 正常表现 |
| ---: | --- | --- |
| CH0 | U相DDS单位正弦 | -1～1，默认60 Hz；故障复位时反复从0开始 |
| CH1 | IU原始码 | 围绕各自中点变化 |
| CH2 | IV原始码 | 围绕各自中点变化 |
| CH3 | IW原始码 | 围绕各自中点变化 |
| CH4 | VUV原始码 | 围绕中点的U-V线电压信号 |
| CH5 | VVW原始码 | 围绕中点的V-W线电压信号 |
| CH6 | VWU原始码 | 围绕中点的W-U线电压信号 |
| CH7 | 故障位 | 正常为0；`004`在浮点曲线上显示为4 |

CH0是单位正弦，不包含软启动幅值。软启动过程应观察`inv_svpwm.duty_*`或实际线电压。

VOFA断续且CH7周期出现4，通常不是USART问题，而是`004 -> 停止喂狗 -> 复位`造成的数据流反复中断。OLED和VOFA都只能读取发布快照，不应直接读取DMA数组。

ADC标定模式的VOFA通道会自动改为：

| 通道 | 标定模式数据 |
| ---: | --- |
| CH0～CH5 | IU、IV、IW、VUV、VVW、VWU原始码 |
| CH6 | GAIN步骤计算的`recommended_scale`，包含正负极性 |
| CH7 | 锁存故障位 |

完整标定结果可直接在Keil Watch观察`inv_calibration_result`，不需要在其他模块寻找内部变量。

## 9. 故障码与异常处理

| OLED代码 | 含义 | 优先检查 |
| ---: | --- | --- |
| `001` | ADC3/4/5同步失步或DMA停止 | HRTIM Trigger 2、DMA IRQ、三路序列、ADC Overrun |
| `002` | ADC/DMA HAL错误 | `HAL_ADC_ErrorCallback()`、DMA错误标志、启动顺序 |
| `004` | 任一ADC连续8帧贴近0或4095 | 采样板5 V/3.3 V/1.65 V、SGND、六根输出线、Rank映射 |
| `008` | HRTIM启动/更新失败或FLT3有效 | PB10是否为高、FLT3标志、HRTIM计数器和输出状态 |
| `010` | ADC模拟看门狗越界 | AWD来源ADC及通道、阈值和原始码 |
| `020` | 占空比或CMP命令非法 | `duty_u/v/w`、HRTIM周期及软件限幅 |
| `040` | CBSVPWM失败或持续限幅 | Vdc/目标RMS、调制度上限、浮点有效性 |
| `080` | 开环参数非法 | 60 V、32 V RMS、30/60 Hz、软启动和控制频率 |
| `100` | CSS检测HSE故障 | 8 MHz晶振、负载电容、焊接、时钟配置 |
| `200` | 快速帧或控制心跳超时 | ADC触发、DMA、ISR执行和HRTIM时基 |
| `400` | 其他不可恢复系统错误 | HAL返回值、HardFault位置、栈和电源完整性 |

多个故障会按位或，例如`00C = 004 + 008`。故障锁存后软件关闭六路PWM、不自动恢复并停止喂狗。

### 9.1 常见现象、原因与处理

| 现象 | 最可能原因 | 处理方法 |
| --- | --- | --- |
| `E:004`，OLED约0.5 s闪一次，PWM呈短脉冲串 | ADC贴轨后停喂IWDG，MCU反复复位 | 断开母线；按5 V→3.3 V→1.65 V→六路输出→系统板ADC端顺序测量，修复后应接近中点码 |
| 六路ADC全为0 | 采样板未供电、SGND断开或连接器整体错位 | 检查采样板5 V、AMS1117、排线方向和公共参考地 |
| 仅一路为0/4095 | 单根线断路/短路、输出运放故障或Rank接错 | 从采样板输出端逐点追到对应MCU引脚 |
| 六路都约2048且几乎不动 | 零输入时正常；若已升到60 V并带功率，则采样输入未穿过传感器、线电压端未接或通道失效 | 检查CT方向和穿线、VW1/2/3接线；32 V RMS目标下电压通道应有明显交流摆幅 |
| `E:008`，没有PWM | PB10低或FLT3已置位 | 测PB10应为高；未接真实Fault时保证确定上拉，清除故障需复位 |
| MCU脚有PWM，驱动输入无PWM | 系统板到驱动板线序或DGND错误 | 对照PB12/13、PB14/15、PC8/9逐线通断测试 |
| 驱动输入正常，Gate无波形 | 驱动+5 V或+12 V缺失，隔离电源异常，DISABLE/芯片损坏 | 分别测VCCI和两路隔离侧电源；母线断电状态下排查 |
| 低侧Gate正常，高侧Gate异常 | 高侧测量参考错误或高侧隔离供电异常 | 只测Gate-Source；检查+12V_A相对VSSA/SW节点 |
| MCU引脚10 kHz稳定，但桥臂/线电压“频率不定” | 测点是SVPWM桥臂节点，自动频率算法在变化脉宽上误判 | 用MCU脚判载波；用慢时基/FFT观察60 Hz包络和基波 |
| 占空比始终约50% | 状态未进入4/5、控制心跳停止、反复故障或只观察了软启动初期 | 检查`inv_state`、`fault_bits`、`inv_control_heartbeat`和`duty_*` |
| OLED数字更新慢但不重启 | 设计刷新周期为100 ms且软件I2C较慢 | 属于正常后台显示；不得提高到中断内刷新 |
| OLED整屏闪烁、启动画面反复出现 | IWDG复位、5 V跌落或接线引起MCU复位 | 查故障码、NRST、5 V/3.3 V纹波和电源限流状态 |
| VOFA没有数据 | 串口选择、协议、波特率或共地问题 | 选择JustFloat、460800/8N1，检查PD5/PD6和USB串口地 |
| VOFA数据间歇出现 | MCU反复复位或主循环被阻塞 | 先排除`004/008/200`和电源跌落，再检查发送计数 |
| 三路线电压幅值/相位不一致 | PWM线序、采样极性、负载或桥臂器件不一致 | 先在MCU脚验证U/V/W，再验证Gate，最后交换采样线定位问题 |
| `VUV+VVW+VWU`明显不为0 | 一路线电压极性反接、通道映射错误或零点/比例未标定 | 核对U-V、V-W、W-U的正负方向并分别标定 |
| 输入电流突然增大、MOSFET发热 | 上下管映射错误、实际死区不足、驱动振铃或桥臂短路 | 立即断母线；差分测Gate-Source和死区，检查4.7 Ω/二极管/10 kΩ门极网络，不依赖T5A保险丝 |
| 输出电压低于32 V RMS | 开环母线压降、MOSFET/死区压降、滤波和负载、采样标定误差 | 同时测实际Vdc、桥臂中点和滤波后线电压；开环不保证精密稳压 |
| 波形振铃明显 | 探头接地环路、功率回路寄生、栅极速度或RC吸收参数不合适 | 先使用短地弹簧/差分探头确认不是测量伪影，再评估门极和吸收参数 |

## 10. 当前保护能力与明确缺口

### 10.1 当前能够执行的保护

- HRTIM软件Output Stop可关闭C/D/E六路输出。
- PB10/FLT3被人工拉低时，可由HRTIM硬件把输出置为Inactive。
- ADC持续贴轨、ADC/DMA错误、同步失步、控制超时、CSS和不可恢复HAL错误会锁存故障。
- IWDG只在采样、控制和Fault状态正常时刷新。

### 10.2 当前不能宣称具备的保护

- UCC21520原理图没有nFAULT、DESAT或OCP输出，PB10没有真实故障源时不能自动发现MOSFET短路。
- 当前驱动板`DISABLE`固定低，MCU无法通过独立GPIO撤销驱动器使能。
- ADC软件保护和当前0～4095的宽AWD阈值不能提供微秒级短路保护。
- T5A保险丝保护线缆和严重持续故障，不保护单次MOSFET直通。
- 当前物理量比例和过流/过压阈值尚未实测标定，不能把换算后的A/V数值用于正式保护。

因此第一次带功率必须从5 V和较小限流值开始，逐级确认后才升到60 V，并把实验人员立即断电作为当前硬件条件下的最后保护手段。由于没有独立硬件OCP/DESAT，60 V测试仍属于风险受控的临时开环验证，不等同于已建立正式保护链。

- [ ] 三个桥臂U/V/W的上管、下管和相序已逐线核对。
- [ ] 系统板、采样板、驱动逻辑侧和功率侧地参考没有混接错误。
- [ ] 采样板5 V、3.3 V、`1V65REF`均正常。
- [ ] 六路ADC零输入码均远离0和4095，故障码为`000`。

- [ ] 三组MCU PWM均为10 kHz互补波，实际死区已在Gate-Source测量。
- [ ] 驱动板+5 V和+12 V电源正常，无功率母线时Gate波形已逐桥臂验证。

## 12. 只修改配置文件完成三种任务

### 12.1 六路零点标定

1. 断开功率母线，保持六路电流/线电压真实零输入。
2. 在`inv_user_config.h`设置：

```c
#define INV_USER_WORK_MODE       INV_MODE_ADC_CALIBRATION
#define INV_USER_CALIBRATION_STEP INV_CAL_STEP_ZERO
```

3. 编译下载；OLED第4行应最终显示`D:11`。
4. 在Keil Watch展开：

```c
inv_calibration_result.offset[0]
inv_calibration_result.offset[1]
inv_calibration_result.offset[2]
inv_calibration_result.offset[3]
inv_calibration_result.offset[4]
inv_calibration_result.offset[5]
```

5. 依次写回`IU/IV/IW/VUV/VVW/VWU_OFFSET`。三相交流采样板正常零输入通常接近2048，但以每路实测结果为准。

### 12.2 单通道增益和极性标定

1. 保持`INV_MODE_ADC_CALIBRATION`，改为`INV_CAL_STEP_GAIN`。
2. 选择一个通道，例如IU：

```c
#define INV_USER_CALIBRATION_CHANNEL   INV_CAL_CHANNEL_IU
#define INV_USER_CALIBRATION_REFERENCE (1.0f) /* 已知+1.0 A */
```

3. 在复位启动前施加稳定的直流或准静态已知物理输入；GAIN步骤不重新求零点，而是使用刚才写回的offset。
4. 等待OLED显示`D:11`，读取：

```c
inv_calibration_result.raw_average
inv_calibration_result.recommended_scale
```

5. 把`recommended_scale`写回对应`*_SCALE_*_PER_COUNT`。负值是有效结果，表示原始码随正方向物理量增加而降低。
6. 依次完成六个通道。若显示`D:10`，说明已知输入造成的码差小于`INV_USER_CAL_MIN_DELTA_COUNTS`，应提高安全标定输入或检查接线。

程序使用：

```text
recommended_scale = known_reference / (raw_average - configured_offset)
physical_value = (raw - offset) * scale
```

标定结果按用户选择不写Flash，必须人工确认并写回配置文件。

GAIN步骤计算的是平均码，不能把正弦交流的RMS值直接作为`REFERENCE`。若采样前端无法安全施加直流/准静态输入，应使用外部脚本对VOFA原始波形计算RMS码差后再求增益，不能套用本步骤的平均值结果。

### 12.3 只测MCU端SVPWM波形

```c
#define INV_USER_WORK_MODE        INV_MODE_PWM_WAVEFORM
#define INV_USER_ENABLE_PWM_OUTPUT (1U)
```

该模式不要求ADC测量有效。ADC3/4/5仍按IOC的双Rank完成DMA，三路线电压快照供OLED/VOFA观察，完整同步帧由ADC3 DMA提供10 kHz节拍；ADC数值贴轨不会关闭PWM，但ADC3 DMA完全停止会触发控制心跳超时。

### 12.4 当前60 V开环PWM运行

无需电流标定；采样板接好并确认三路线电压输出在0～3.3 V范围后设置：

```c
#define INV_USER_WORK_MODE        INV_MODE_PWM_WAVEFORM
#define INV_USER_ENABLE_PWM_OUTPUT (1U)
#define INV_USER_DC_BUS_V          (60.0f)
#define INV_USER_LINE_RMS_V        (32.0f)
#define INV_USER_OUTPUT_FREQUENCY  (60U)
#define INV_USER_LINE_VOLTAGE_ONLY (1U)
```

该模式开放六路C/D/E PWM，三路线电压只用于观测，不参与调制和闭环；必须保留外部限流、人工断电和HRTIM Fault 3测试条件。

## 13. 后续修改输入输出参数

所有常用参数集中在`Core/Inc/inv_user_config.h`，修改前必须满足：

```text
M = 2 * Vline_rms * sqrt(2/3) / Vdc <= modulation_limit
```

32 V RMS线电压在`modulation_limit=0.90`时，理论母线至少约58.1 V，还没有计入MOSFET、死区、滤波和控制裕量。赛题要求不能仅修改开环常量，还必须完成：

1. 实测直流母线电压。
2. 六路模拟前端零点、增益和极性标定。
3. 三相线电压RMS计算及电压闭环。
4. 物理过流、过压阈值和有效AWD窗口。
5. 独立硬件OCP/DESAT或等效快速短路保护。
6. 不同负载、30/60 Hz、温升及故障注入验收。

本次按时间边界仅调整为60 V/32 V RMS开环参数，没有增加电压闭环或安培阈值过流关断。实际输出不保证精确等于32 V RMS；未完成采样量程、驱动波形、负载和温升分级验收前，不得直接从0 V跳升到60 V。
